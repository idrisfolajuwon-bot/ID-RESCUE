Prompt Lab

Creation Vault

Research Desk

Studio Guide

Find your way around the tools and learn what each area does.

ABOUT THE PROJECT

IDRIS AI STUDIO is an independent project published under the IDRIS name. It is a developing creative workspace; available features and service limits may change as the project is improved. Online AI features require an internet connection.
