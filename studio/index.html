What works now, what is still being built, and how your information is handled.

AVAILABLE NOW

Prompt LabTurns your own idea into a structured prompt in your browser.
Image CreatorCreates images from natural-language requests in AI Chat, subject to image-service availability.
Web ExplorerOpens live Google News searches and lets IDRIS AI analyse article text you provide.
Chat History & AI MemorySearch past conversations and save helpful context in this browser.
Creation VaultSaves work in local browser storage and supports JSON backup/restore.
AI AssistantConnects to the IDRIS AI backend for live text conversations and supported image-generation requests.

HOW THE TOOLS WORK

AI chat and supported image-generation requests use the secure IDRIS AI backend. Web Explorer opens an external Google News search; you can paste article text into the studio for AI analysis.

GitHub Pages can host the public front end, but it cannot run server-side code. A separate backend is needed for private API credentials, rate limits and provider calls. GitHub Pages documentation ↗

PRIVACY NOTES

Saved items remain in this browser's local storage. Clearing browser data can remove them, so use the vault backup. Do not save passwords, payment details or other sensitive information here.
